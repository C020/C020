# بوت شارات النيترو والبوست

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. انسخ `.env.example` إلى `.env` وضع توكن البوت.
3. شغّل `start.bat` (ويندوز) — يعمل البوت في الخلفية بدون نافذة. للإيقاف `stop.bat`. على لينكس: `./start.sh`.
4. في السيرفر اكتب `/panel` في الروم المقفل (يحتاج صلاحية Administrator) فتظهر لوحة الأزرار.

## كيف يعمل
- كل الردود **مخفية (Ephemeral)** — يشوفها صاحب الضغطة فقط.
- **بوستاتك**: البوت يفحص تلقائياً كل السيرفرات اللي هو موجود فيها ويجيب تاريخ بوستك.
- **سيرفرات البوت مو فيها** (أي سيرفر بالعالم): اضغط «إضافة بوست» واكتب اسم السيرفر وتاريخ بدايته.
- **النيترو**: اضغط «تسجيل النيترو» واكتب تاريخ بداية اشتراكك.
- يحسب: شارتك الحالية، الشارة الجاية وكم باقي لها، وكم باقي على التجديد/الانتهاء الشهري.

> ملاحظة: ديسكورد لا يسمح لأي بوت بقراءة تاريخ نيترو المستخدم أو بوستاته في سيرفرات البوت ليس فيها، لذلك هذه البيانات تُدخل يدوياً مرة وحدة وتنحفظ.
