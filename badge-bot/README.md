# Badge Bot — فاحص شارات النيترو والبوست

## التشغيل
1. ثبّت Node.js 18+.
2. انسخ `.env.example` إلى `.env` وحط توكن البوت.
3. فعّل **Server Members Intent** من Developer Portal > Bot.
4. ويندوز: دبل كلك على `start.bat` (يشتغل مخفي بالخلفية، والإيقاف `stop.bat`). لينكس: `./start.sh`.
5. اكتب `/panel` في الشات المقفل وبتطلع اللوحة.

صلاحيات البوت بالروم: View Channel + Send Messages + Embed Links. اقفل الكتابة على الأعضاء، الزر يشتغل عادي.
